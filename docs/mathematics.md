# Paths, quotients, and compatible families

[日本語](mathematics.ja.md) · [Implementation](../src/CatDB/Migration.hs)

A schema is a finite DAG presentation with parallel path equations. We enumerate
its paths and quotient by the congruence generated by those equations, including
all composable left/right contexts. This is exact for the supported finite
domain; equations are not oriented rewriting rules with a search timeout.

An instance is I : C → FinSet. Generators are total functions, and path equations
must hold at every element. A mapping F : C → D maps objects to objects and
generators to paths, preserving the source equations in D independently of data.

## Three operations from one map

Delta is literal precomposition: Δ_F J = J ∘ F.

At d in D, Sigma takes tokens (c,p,x), where p : F(c) → d and x ∈ I(c), and
quotients by the relations

    (c,F(a);q,x) ~ (c',q,I(a)(x))     for a : c → c'.

This is the colimit over (F ↓ d). A target arrow b sends [c,p,x] to [c,p;b,x].
The engine returns origins and the unit I → Δ_F Σ_F I.

Pi takes one element x_(c,p) for each p : d → F(c), subject to

    I(a)(x_(c,p)) = x_(c',p;F(a))     for a : c → c'.

This is the limit over (d ↓ F). A target arrow b : d → d' maps a family to its
components indexed by (c,b;q). The engine returns the compatible families and
the counit Δ_F Π_F I → I. Indexed forward/inverse images prune the search;
they do not change the limit's definition. Empty diagrams yield the empty
colimit and singleton limit.

## Universal properties as functions

Given h : I → Δ_F J, sigmaFactor constructs the unique extension

    [c,p,x] ↦ J(p)(h_c(x)).

Given h : Δ_F J → I, piFactor constructs the unique map

    y ↦ (h_c(J(p)(y)))_(c,p).

Naturality makes the quotient map well-defined and the family compatible.
Precomposition with the unit/counit gives the inverse correspondences:

    Nat_D(Σ_F I,J) ≅ Nat_C(I,Δ_F J)
    Nat_C(Δ_F J,I) ≅ Nat_D(J,Π_F I).

Thus Σ_F ⊣ Δ_F ⊣ Π_F. The natural-transformation actions are implemented using
these factorizations. Tests enumerate small Hom sets independently and check
both round trips. This is executable evidence, not a mechanized general proof.

## What is, and is not, structural

A natural transformation is not an arbitrary database edit. Ordinary edits
are checked after a pure batch. Path equations are data invariants.

select computes the greatest subfunctor under specified allowed elements;
generated computes the least subfunctor containing specified roots. Relay's
public view uses generated because Delta also pulls entire shared value sets:
omitting an email arrow alone does not establish a privacy guarantee.

Relay uses Sigma on its identity diagram, assembles distinct person/team
memberships, then uses Pi on Member → Person and Member → Team ← Ticket.
Its public Delta uses a different mapping, with explicit open-work roots.
Application policy remains visible instead of being attributed to mathematics.

Persistence, OS locks and flushes sit outside these pure constructions.
Cyclic schemas, a typed algebra of scalar operations, and production-scale
query optimization remain outside this PoC.
