# Official CatDB website

The English and Japanese pages introduce CatDB and its direct Studio GUI first.
Relay Desk remains a separately labelled application example, with its actual
fictional-data screenshot retained under assets/relay-desk.jpg.

The interactive Note→Book illustration in site.js is deliberately a diagram,
not a running database or engine validation. It shows a declared equation split
by a one-sided draft change. The downloadable native Studio performs the real
checked edits, persistence and categorical operations.

No Studio screenshot is fabricated. There are no external fonts, CDN scripts,
analytics, API keys or live data endpoints. Windows links target the prepared
v0.3.0-poc release and must be published with that release. The existing GitHub
Pages workflow publishes this directory after its native build/test checks.
