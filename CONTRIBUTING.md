# Contributing

CatDB is an experimental, maintainer-led project. Contributions are accepted
through **GitHub issues, not pull requests**. Please open an issue for bug
reports, use cases, mathematical counterexamples, or design proposals.
External pull requests are not accepted; maintainers implement agreed changes.

For a bug, include the CatDB version, OS, minimal schema/data or commands,
expected behavior, and actual behavior. Remove personal data and credentials.
For a proposal, describe a real application and why the current operations
cannot express it. Small, reproducible counterexamples are especially useful.

The source and documentation are licensed under MIT. Dependencies retain their
own licenses; binary distributions include third-party notices.
